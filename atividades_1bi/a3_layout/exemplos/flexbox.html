O que é Flexbox?

Flexbox (Flexible Box Layout) é um modelo de layout CSS que permite organizar e alinhar elementos de forma eficiente, mesmo quando o tamanho dos elementos é desconhecido ou dinâmico.

🔹 Exemplo 1: Layout de 3 Colunas Iguais

Use display: flex no elemento pai e flex: 1 nos filhos para distribuir o espaço igualmente.

.flex-row { display: flex; gap: 20px; }
.flex-col { flex: 1; }

Coluna 1

Esta coluna ocupa 1/3 do espaço disponível. O flex: 1 faz todas as colunas terem o mesmo tamanho.

Coluna 2

O gap: 20px adiciona espaço entre as colunas sem precisar usar margin.

Coluna 3

Flexbox automaticamente distribui o espaço, tornando o layout flexível e responsivo.

🔹 Exemplo 2: Sidebar Fixa + Conteúdo Principal

Use flex: 0 0 250px para tamanho fixo e flex: 1 para ocupar espaço restante.

.flex-sidebar { flex: 0 0 250px; /* não cresce, não encolhe, 250px fixo */ }
.flex-main { flex: 1; /* ocupa o espaço restante */ }

Sidebar

Esta sidebar tem largura fixa de 250px.

  • Item 1
  • Item 2
  • Item 3

Conteúdo Principal

Esta área principal ocupa todo o espaço restante. É perfeito para layouts com sidebar + conteúdo.

O Flexbox garante que o layout seja responsivo e se adapte a diferentes tamanhos de tela.

🔹 Exemplo 3: Flexbox Vertical (flex-direction: column)

Por padrão, Flexbox alinha horizontalmente. Use flex-direction: column para empilhar verticalmente.

.flex-vertical { display: flex; flex-direction: column; gap: 15px; }
Item 1 - Empilhado verticalmente
Item 2 - flex-direction: column
Item 3 - gap: 15px entre os itens

🔹 Exemplo 4: Centralização Perfeita

Use justify-content: center (horizontal) e align-items: center (vertical).

.flex-alignment {
  display: flex;
  justify-content: center; /* horizontal */
  align-items: center; /* vertical */
  height: 200px;
}

✨ Perfeitamente Centralizado

Horizontal e verticalmente!

🔹 Exemplo 5: Cards Responsivos com flex-wrap

Use flex-wrap: wrap para permitir quebra de linha e calc() para controlar o tamanho.

.card-container { display: flex; flex-wrap: wrap; gap: 20px; }
.card { flex: 0 0 calc(33.333% - 20px); /* 3 cards por linha */ }
🎨

Card 1

Flexbox torna fácil criar layouts de cards responsivos e elegantes.

🚀

Card 2

Com flex-wrap, os cards se reorganizam automaticamente em telas menores.

Card 3

O gap cria espaçamento uniforme sem precisar calcular margins complexas.

📖 Principais Propriedades Flexbox

No Container (elemento pai):

  • display: flex - Ativa o Flexbox
  • flex-direction - Define direção: row (padrão) ou column
  • justify-content - Alinha horizontalmente: flex-start, center, flex-end, space-between, space-around
  • align-items - Alinha verticalmente: flex-start, center, flex-end, stretch
  • gap - Espaçamento entre itens
  • flex-wrap - Permite quebra de linha: nowrap (padrão), wrap

Nos Itens (elementos filhos):

  • flex - Atalho para flex-grow, flex-shrink, flex-basis
  • flex: 1 - Item cresce para ocupar espaço disponível
  • flex: 0 0 200px - Item tem tamanho fixo de 200px
  • align-self - Sobrescreve align-items para um item específico
