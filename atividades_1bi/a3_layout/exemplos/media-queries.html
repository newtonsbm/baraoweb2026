📐 Exemplos de Media Queries

Exemplo 1: Mudança de Cor

Esta caixa muda de cor conforme o tamanho da tela:

Redimensione a janela para ver a cor mudar! 
/* Desktop Grande (padrão) */
.box { background-color: #3498db; }

@media (width < 1200px) {
  .box { background-color: #9b59b6; } /* Roxo */
}

@media (width < 768px) {
  .box { background-color: #e67e22; } /* Laranja */
}

@media (width < 480px) {
  .box { background-color: #e74c3c; } /* Vermelho */
}

Exemplo 2: Layout de Colunas

3 colunas no desktop, viram pilha no tablet/mobile:

Coluna 2
Coluna 3

@media (width < 768px) {

}

Exemplo 3: Cards Responsivos

4 cards → 2 cards → 1 card conforme a tela diminui:

Card 1

Desktop: 4 por linha

Card 2

Tablet: 2 por linha

Card 3

Mobile: 1 por linha

Card 4

Redimensione!

.card { flex: 1 1 calc(25% - 20px); } /* 4 por linha */

@media (width < 768px) {
  .card { flex: 1 1 calc(50% - 20px); } /* 2 por linha */
}

@media (width < 480px) {
  .card { flex: 1 1 100%; } /* 1 por linha */
}

📚 Resumo - Media Queries

Sintaxe Básica:

/* Sintaxe Moderna (Level 4) */
@media (width < 768px) {
  /* CSS aplicado quando a largura for menor que 768px */
  .elemento {
    propriedade: valor;
  }
}

/* Sintaxe Clássica (ainda funciona) */
@media (max-width: 768px) {
  .elemento { propriedade: valor; }
}

Breakpoints Comuns:

  • Mobile: width < 480px
  • Tablet: width < 768px
  • Desktop: width < 1200px
  • Desktop Grande: width >= 1200px

Dicas:

  • Use width < para sintaxe mais legível (moderno)
  • Use width >= para desktop-first
  • Sintaxe max-width ainda funciona (clássica)
  • Sempre inclua <meta name="viewport"> no head
  • Teste com Chrome DevTools (F12 + Ctrl+Shift+M)

💡 Experimente: Redimensione a janela do navegador ou use F12 → Ctrl+Shift+M para testar!
