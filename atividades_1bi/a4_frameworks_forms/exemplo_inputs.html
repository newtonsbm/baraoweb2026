A Tag Form

A tag <form> é o elemento HTML utilizado para criar formulários. Ela serve como um contêiner para diversos tipos de elementos de entrada, como campos de texto, botões, checkboxes, etc. O formulário é responsável por coletar os dados inseridos pelo usuário e enviá-los para um servidor ou processá-los de alguma forma.

Exemplo básico de um formulário:

<form action="/submit" method="post">
<label for="name">Nome:</label>
<input type="text" id="name" name="name">
<button type="submit">Enviar</button>
</form>

O atributo action define a URL para onde os dados do formulário serão enviados, enquanto o atributo method especifica o método HTTP a ser utilizado (geralmente "get" ou "post").

Outros atributos:

  • enctype: Define o tipo de codificação dos dados (ex: "multipart/form-data" para upload de arquivos)
  • target: Especifica onde abrir a resposta do formulário (ex: "_blank" para nova aba)
  • novalidate: Desativa a validação automática do formulário

📚 Resumo dos Inputs HTML

Inputs de Texto:

  • type="text" - Texto simples
  • type="email" - Email com validação
  • type="password" - Senha occulta
  • type="tel" - Telefone
  • type="url" - URL com validação
  • type="search" - Busca

Inputs Numéricos:

  • type="number" - Número incrementável
  • type="range" - Slider

Inputs de Data/Hora:

  • type="date" - Data
  • type="time" - Hora
  • type="datetime-local" - Data e hora
  • type="month" - Mês
  • type="week" - Semana

Inputs de Seleção:

  • type="checkbox" - Múltiplas seleções
  • type="radio" - Uma seleção
  • <select> - Dropdown

Outros:

  • type="color" - Picker de cor
  • type="file" - Upload de arquivo
  • type="hidden" - Campo invisível
  • <textarea> - Texto multilinha
